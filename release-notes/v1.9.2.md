**Bug-fix release, and an important one if you monitor channels.** Upgrading is
recommended.

## The dashboard was hammering YouTube

v1.9.0 added a dashboard that refreshes itself every 60 seconds. That refresh
fetched your channel list — and working out each channel's display name means a
live lookup against YouTube, which takes around **23 seconds per channel**.

So with the dashboard open, an install with channels configured was making a
continuous stream of requests to YouTube in the background. With three or more
channels, one refresh couldn't finish before the next began, so they simply
stacked up.

At best that's wasted bandwidth. At worst it's the kind of traffic that gets you
rate-limited by YouTube — which would then break the downloads Vidshelf exists to
do.

Two fixes:

- **The dashboard no longer asks for the channel list.** It only ever needed the
  count, which it was already being told.
- **Channel names are cached for a day.** A channel's name effectively never
  changes, and a day-old label costs nothing next to being throttled.

**The Channels page is much faster as a side effect.** It has always paid that
~23 seconds per channel, every single time you opened it. Now only the first
visit after a restart does.

If you don't use channel monitoring, none of this affected you — which is exactly
why it wasn't caught before release.

