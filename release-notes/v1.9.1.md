**Bug-fix release.** The Top artists bars on the new dashboard didn't render.

## Top artists showed empty bars

On v1.9.0, the Top artists panel listed the right artists with the right sizes,
but every bar beside them was blank and identical — so the one thing the panel
existed to show, relative size at a glance, wasn't there.

The bars were being given a correct width, but the element they were set on
displays inline, and widths are ignored on inline elements. Nothing errored and
the numbers were right, which is why it survived the tests: it was only visible
by looking at the page.

Fixed, and the release screenshot has been recaptured — it was still showing the
pre-1.9.0 layout.

## Also

- `update.ps1`, a Windows upgrade helper, is now included in the repo. It runs
  the pull and restart for you and then checks the things worth checking: that
  the container reports the version you just pulled, that the app actually
  answers, and that your media mounts are real network shares rather than
  Docker's silent stand-in volume.

## Upgrading

```bash
docker compose pull && docker compose up -d
```
