**Dashboard fixes.** Three numbers on the dashboard were wrong. Nothing was
broken behind them — your library, downloads and Plex sync were all fine — but
what the dashboard told you about them wasn't.

## Disk Usage was measuring the wrong folder

The Disk Usage card walked Vidshelf's **temporary download folder**, not your
media library. So it never reflected how much video you actually have.

It looked believable for a long time because failed downloads were leaving
copies in that temporary folder (fixed in v1.8.1) — the card was quietly
reporting the size of leftover junk. Once v1.8.1 cleaned those up, it dropped to
`0.0 KB`, which is what gave it away.

It now measures your real media folders — the music-video root and every
channel's destination — counting video files only, so artwork and stray files
aren't included. On the install this was found on, the card went from `0.0 KB`
to **24.1 GB across 197 videos**.

It's cached for five minutes, because your media folder is usually a network
share and the dashboard asks for this every time you open it.

## Sizes were shown 1024× too large

Separately, the same card divided its numbers wrong — a size in bytes was
labelled as kilobytes, so every reading was out by a factor of 1024. A 600 KB
file would have displayed as "614.4 MB".

You probably never noticed, because the number it was formatting came from a
near-empty folder, and "0.0 KB" looks right no matter how you divide it. The two
faults hid each other: fixing only the first would have made the card read
"102400.0 GB".

Sizes over a terabyte now display in TB rather than four-digit gigabytes.

## The version in the sidebar could be stale

The version shown at the bottom of the sidebar was fetched **once**, when the
page loaded, and never again. If you left a browser tab open across an upgrade,
it kept showing the old version indefinitely — and the "update available" link
kept appearing after you'd already installed the update.

It now refreshes whenever you visit the Dashboard, like the rest of the stats.
If you've had a tab open a while, a refresh will sort it out immediately.

## Also

Three automated checks were added for these, because "the number on screen is
wrong" is the kind of fault no ordinary test catches — only a person looking at
the page.

## Upgrading

```bash
docker compose pull && docker compose up -d
```

No recreate needed. If your browser has an old tab open, refresh it.
