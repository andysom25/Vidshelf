🎞️ Video Format Compatibility

Converts videos to H.264 video + AAC audio in an MP4 container — the format the widest range of Plex clients can play directly, without server-side transcoding. Already-compatible tracks are stream-copied (no quality loss, no re-encode); only video that isn't already H.264 gets re-encoded, at a high-quality setting. New downloads are checked and converted automatically — use this to fix videos you already have.

🩺 System Health

Checks the external tools this app depends on — most useful if you're running without Docker, since the Docker image always bundles these.

🕒 Automatic Channel Monitoring

Checks your monitored channels on a timer and downloads anything new. Only channels set to New Only or All Videos are checked — Manual channels are never touched. Videos you already have are always skipped, so a channel on "All Videos" won't re-download its back catalogue every hour.

How far back a check looks. Lower is faster.
Stops piling onto a backlog that isn't draining.
0 disables the free-space check.

🔔 Notifications

Sends a message when something happens while you're not watching. Paste a Discord or Slack webhook, an ntfy or Gotify URL, or any endpoint that accepts a JSON POST — the type is detected from the URL. Nothing is sent unless you enable it.

🧹 Storage Retention

Deletes the oldest videos once an artist folder holds more than you want to keep. This is the only feature that deletes media, so it's off by default and always previews first. Pruned videos are not re-downloaded — their download history is kept on purpose, so automatic checks won't fetch them again.

📥 Download History

Clears the record of which videos have been downloaded. This will allow "New Only" mode to re-download previously skipped videos. Files are NOT deleted.
